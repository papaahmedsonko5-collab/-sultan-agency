Les données que nous collectons

Nous limitons la collecte au strict nécessaire.

  • Formulaires de demande : les informations que vous saisissez sont enregistrées dans notre base de données pour traiter votre demande. Sur la page « Présenter un projet » : nom ou entreprise, téléphone ou WhatsApp, e-mail facultatif, type de projet, branche concernée, formule de site éventuelle, description du besoin, budget indicatif facultatif et délai souhaité. Sur le formulaire détaillé : également l'entreprise, le secteur d'activité, les fonctionnalités souhaitées, les liens existants et vos commentaires. Une fois la demande enregistrée, vous pouvez, si vous le souhaitez, l'envoyer aussi sur WhatsApp avec un message prérempli. Seul l'administrateur du site peut consulter ces demandes, et peut y ajouter des notes internes pour suivre votre dossier.
  • Messages directs : si vous nous écrivez par WhatsApp, Instagram, Snapchat ou email, nous recevons les informations que vous choisissez de nous donner.
  • Mesure d'audience (uniquement si vous acceptez) : nous enregistrons les pages visitées, le type d'appareil (mobile, tablette ou ordinateur), le navigateur, le site d'où vous venez et vos clics sur les boutons importants (demande de projet, WhatsApp, réseaux, réalisations). Un identifiant aléatoire, supprimé à la fermeture de l'onglet, relie ces actions à une même visite. Notre base de données n'enregistre ni votre adresse IP, ni votre nom, ni aucune donnée qui permette de vous identifier. Comme pour toute connexion à Internet, les serveurs techniques de nos prestataires (GitHub, Supabase) voient votre adresse IP lors des échanges et peuvent la conserver dans leurs journaux techniques. Si vous refusez, rien n'est enregistré.

Pourquoi nous utilisons ces données

Pour répondre à votre demande, établir un devis et assurer le suivi d'un projet. Nous ne vendons pas vos données et ne les utilisons pas pour de la publicité.

Services tiers

  • Supabase héberge la base de données qui reçoit vos demandes de devis.
  • ntfy.sh envoie une notification à l'administrateur à chaque nouvelle demande. Elle contient uniquement le type de projet demandé, jamais votre nom, téléphone ou message.
  • GitHub Pages héberge le site. Le serveur reçoit votre adresse IP lorsque vous visitez une page.
  • wa.me (WhatsApp) : si vous choisissez d'envoyer votre demande sur WhatsApp, le texte prérempli est transmis à WhatsApp lorsque vous ouvrez le lien.
  • Google Fonts fournit les polices d'écriture. Votre navigateur contacte les serveurs de Google pour les charger.
  • i.ibb.co héberge la photo du fondateur.
  • WhatsApp, Instagram, Snapchat : lorsque vous cliquez sur ces liens, vous quittez le site et leurs propres politiques s'appliquent.

Durée de conservation

Les demandes et échanges liés à un devis sont conservés le temps nécessaire au projet et à nos obligations de gestion, puis supprimés sur demande.

Vos droits

Vous pouvez demander l'accès à vos données, leur rectification ou leur suppression, et vous opposer à leur traitement. Ces droits découlent de la loi sénégalaise n° 2008-12 du 25 janvier 2008 sur la protection des données à caractère personnel et, pour les visiteurs de l'Union européenne, du RGPD. Écrivez-nous à l'adresse ci-dessus ; nous répondons dans un délai raisonnable.

Vous pouvez aussi saisir la Commission de Protection des Données Personnelles (CDP) du Sénégal si vous estimez que vos droits ne sont pas respectés.
